# Demo A Tu Propio Stylo

Landing conceptual para **A Tu Propio Stylo Barbería**, desarrollada por Ross Digital Studio.

## Enfoque
- estética urbana y joven
- responsive para mobile, tablet y desktop
- animaciones al hacer scroll
- precios visibles
- servicios y estilos
- barberos
- trabajos
- política de turnos
- ubicación y WhatsApp
- barra fija de acceso rápido en mobile

## Datos públicos utilizados
- Villegas 2581, Hurlingham
- Martes a sábados de 10:00 a 21:00
- WhatsApp: 11 5643-8457
- Corte niño: $13.000
- Corte adulto: $14.000
- Corte + barba: $17.000
- Barberos visibles en el perfil: Iván, Maquna, Nahuel y Uri
- Política de turnos publicada en historias destacadas

## Nota
Las imágenes de la demo son ilustrativas y de stock. La página incluye `noindex,nofollow` y no representa una web oficial del negocio.
